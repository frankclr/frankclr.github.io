Linux

字体（最重要）

  1. 方案

    • 推荐 Noto Sans CJK(思源黑体) + 微软字体
      • Linux UI → Noto
      • Office / Web → 微软字体兼容最好
    • Source Han Sans，Deepin 默认使用
      • Noto Sans CJK = Source Han Sans，只是发行渠道不同
    • 不要用文泉驿。WenQuanYi Micro Hei 已经很多年没人维护，字形也比较旧
      字体 优点 缺点
      Noto Sans CJK Google维护，Linux默认，完整CJK 字体文件巨大
      Source Han Sans Adobe+Google开发，质量顶级 同样巨大
      微软字体（微软雅黑等） Windows一致

  2. 安装 Noto 字体,会得到：Noto Sans CJK,Noto Serif CJK 和 emoji
    sudo apt install fonts-noto-cjk fonts-noto-color-emoji

  3. 安装等宽字体
    JetBrains Mono 开发体验较好
    sudo apt install fonts-jetbrains-mono

  4. Nerd Font（终端图标）【非必需】
    JetBrainsMono Nerd Font，一个字体补丁项目，给编程字体加入 Powerline 图标、Devicons、Nerd icons，JetBrains Mono(普通字体) 缺少、 等字符
    用于lazygit、starship、eza、neovim、tmux
    nerd-fonts，从 Release 页面下载 JetBrainsMono.zip

    建议

    • IDE -> JetBrains Mono
    • Terminal -> JetBrainsMono Nerd Font

  5. 安装微软字体

    1. 把下面的字体从 C:\Windows\Fonts 复制到 Linux 的 ~/.local/share/fonts/ 目录下
      • msyh.ttc 微软雅黑
      • msyhbd.ttc 微软雅黑粗体
      • simfang.ttf 仿宋
      • simsun.ttc 宋体
      • simhei.ttf 黑体
    2. Microsoft 字体会被用到
      • 很多 Word/WPS 文档指定 微软雅黑,Linux 就会 fallback Microsoft YaHei
      • 网页 CSS 指定

  6. Cascadia 字体

    • Cascadia 微软开发的编程字体，Windows Terminal 默认字体，字符清晰,hinting 优秀,连字支持
    • 相比 JetBrains Mono:
      • 0/O 区分没那么明显
      • 宽度更宽
      • hinting 非常好
    • 在 Linux terminal 也很好
      sudo apt install fonts-cascadia-code

  7. 刷新缓存 fc-cache -fv

  8. Linux 中文环境常见坑

    • 中文方块 缺 fonts-noto-cjk
    • 代码中文错位 缺 fontconfig fallback

字体渲染

Linux 字体好不好看，其实取决于 fontconfig

  1. 安装 fontconfig 和 GNOME Tweaks
    sudo apt install fontconfig-config gnome-tweaks
  2. 打开 gnome-tweaks
    1. 字体 -> 偏好字体
      • Interface(界面文本) -> Noto Sans CJK SC
      • Document(文档文本) -> Noto Serif CJK SC
      • Monospace(等宽文本) -> JetBrains Mono
    2. 设置 字体 -> 渲染（Font Rendering）
      • Hinting: Slight（微调：轻微）
        • 作用：字体文件内含“微调指令”（hints），指导渲染引擎如何将矢量字形适配到像素 网格。
        • Slight 含义：仅做最小必要调整（如轻微移动字形对齐像素），优先保留字体原始设 计美感，避免过度变形。
        • 效果：小字号时比“无微调”更清晰，但比“Full/中等”更柔和自然。现代高分辨率屏幕 （Retina/2K/4K）推荐此选项，避免“Full”导致的生硬感。
        • 对比：
          • None：完全按数学轮廓渲染，低分辨率下易模糊；
          • Full：强对齐像素网格，文字锐利但可能失真（Windows 传统风格）。
      • Antialiasing: Subpixel（抗锯齿：子像素）
        • 作用：平滑字体边缘锯齿。
        • Subpixel 含义：利用 LCD 屏幕每个像素由红/绿/蓝子像素水平排列的特性，将子像素 作为独立单元渲染，水平方向有效分辨率提升约 3 倍。
        • 效果：文字边缘更锐利、细节更清晰（尤其在浅色背景深色字时），是 Windows ClearType、FreeType LCD 渲染的核心技术。
        • 注意：
          • 依赖标准 RGB 水平排列的 LCD 屏；若屏幕为 OLED/Pentile/垂直排列（如部分手 机），可能产生彩色 fringe（边缘彩边），此时应改用 Grayscale（灰度抗锯齿）； 深色背景+浅色文字时彩边可能更明显，部分系统会自动优化。

    Slight Hinting + Subpixel AA 是现代 Linux 桌面（如 Ubuntu）的推荐默认配置，在清晰度、设计保真度、屏幕兼容性间取得良好平衡。这和 Windows 的 ClearType 比较接近
    若文字边缘出现彩色毛边，可尝试切换 Antialiasing 为 Grayscale；若觉得字体“发虚”，可微调 Hinting 级别（但高分辨率下通常无需改）
    适用场景：

    • 普通 LCD 显示器 + 中高分辨率 → 此组合效果最佳；
    • 高 DPI 屏（如 MacBook Retina）：微调影响变小，Slight 仍优于 Full；
    • 非标准屏幕/旋转屏：尝试关闭 Subpixel，改用 Grayscale。

输入法

  1. Linux 中文输入法

    输入法 推荐
    Fcitx 5 强烈推荐
    IBus GNOME默认,体验一般
    Sogou 停止更新。早期版本基于 Fcitx 4,兼容层存在，但不干净，GTK / Wayland 兼容差

  2. 安装 Fcitx5
    sudo apt install fcitx5 fcitx5-chinese-addons fcitx5-configtool
    fcitx5 输入法框架
    fcitx5-chinese-addons 拼音
    fcitx5-configtool GUI配置

  3. 设置输入法环境变量
    输入法变量必须在 GUI session 启动前就存在。否则，GTK 程序/QT 程序/Electron 程序会 fallback 到 XIM, 导致错误

    1. mkdir ~/.config/environment.d && vi ~/.config/environment.d/im.conf
      • systemctl --user show-environment | grep IM 验证，需要 重新登录
      • 是 systemd user session 的环境变量,GNOME / Wayland GUI 程序都会继承。
      • 2020+， 推荐
    2. vi ~/.profile，需要重新登录 【弃用 2005】
      • ~/.profile 属于 shell login 脚本。触发条件是 login shell 启动
        • 流程: login -> shell -> ~/.profile
        • Wayland session 有时不会加载 ~/.profile，所以变量可能不会传给 GUI 程序
    3. vi ~/.pam_environment 添加配置，需要重新登陆【逐渐弃用 2012】
      • ~/.pam_environment，属于 PAM（认证系统），是 PAM 层环境变量，触发条件是 PAM 登录阶段
        • 流程: login / gdm / ssh -> PAM -> ~/.pam_environment -> session 启动
        • GNOME Wayland 还有一个变量 INPUT_METHOD，容易漏掉
        • 在 GNOME 环境下，所有程序都会继承

  4. 配置拼音
    使用 im-config -n fcitx5 配置 ~/.xinputrc。否则，会与 GNOME 默认输入法 IBus 冲突，要把它禁掉，需要重启
    打开 fcitx5-configtool，拼音引擎使用 Pinyin，而不是 CloudPinyin。CloudPinyin 反而会增加延迟

  5. 安装 kimpanel 扩展

    1. 没有 kimpanel 扩展，输入法的提示词不跟随输入焦点
    2. 备份 /usr/share/fcitx5/addon/ 目录下的 classicui.conf 和 cloudpinyin.conf 到 backup 目录(主要是没有找到配置方式,.config/fcitx5目录下的 config 和 profile都无效)
    3. extension-manager & -> kimpanel@kde.org的Input Method Panel -> 点击设置图标 -> 调整提示词大小

  6. 在 Nvidia + GNOME + Wayland 的情况下，通过 gnome-tweaks 或其他方式设置为登陆启动

  7. 异常排查

    1. fcitx5-diagnose 确认 fcitx5 是否正常运行
      重点看是否有下面三行
    2. GNOME Wayland 必装组件
      fcitx5-frontend-gtk4 是 GNOME 42+ 必需。
      否则，很多 GTK4 程序(gnome-terminal,nautilus,settings)都会错位。
      在 Debian 13 里必须安装, sudo apt install fcitx5-frontend-gtk4

字体 fallback

Linux 中文体验差，很大原因是：monospace + 中文 会出现宽度不一致，字体 fallback 顺序乱。
可以优化 fontconfig，使用 JetBrains Mono + Noto fallback 解决

最终字体组合

场景 字体
UI Noto Sans CJK
网页 Noto Sans
IDE JetBrains Mono
Terminal JetBrainsMono Nerd Font
中文 fallback Noto Sans CJK
Windows兼容 Microsoft YaHei

  1. 创建配置 vi ~/.config/fontconfig/fonts.conf

    不要把 Windows 字体放在 fallback 前面, 更推荐 Noto → Microsoft → Emoji

    1. Noto CJK 字形更标准
    2. Linux UI 默认针对 Noto 调整过
    3. Microsoft 字体 hinting 在 Linux 不一定最佳
      1. hinting 不匹配 Linux
        Windows 使用 ClearType, Linux 使用 FreeType。所以有时会出现微软雅黑在 Linux 偏粗
      2. 字形差异
        例如：Noto Sans CJK 在 Linux UI 上，字重更均匀
      3. emoji fallback
        如果 Microsoft 字体排前面，有时会 emoji fallback 错误
    4. Web / Office 仍然可以 fallback 到 Microsoft 字体

  2. 创建配置 mkdir ~/.config/fontconfig/conf.d && vi ~/.config/fontconfig/conf.d/10-hinting.conf, 字体更接近 macOS,中文更圆润

  3. 刷新 fc-cache -fv

  4. 禁用 bitmap 字体,否则中文会发虚。
    sudo dpkg-reconfigure fontconfig-config
    前面的提示默认，最后一项 Enable bitmapped fonts by default? 选择 NO

  5. Chrome 字体
    设置 -> 外观 -> 自定义字体

    • Standard(标准字体): Noto Sans CJK SC
    • Serif字体: Noto Serif CJK SC
    • Sans-serif字体: Noto Sans CJK SC
    • Monospace(宽度固定的字体): JetBrains Mono

  6. 终端字体
    打开终端 -> 菜单 -> 配置文件首选项 -> 未命名【可以重命名为 personal ,且设置为默认】 -> 文本 -> 自定义字体

    • 选择 JetBrainsMono Nerd Font Mono 13
    • 如果没有安装 JetBrainsMono Nerd Font Mono，选 JetBrains Mono 13
    • 验证 echo "    "

  7. VSCode
    编辑用户配置文件
